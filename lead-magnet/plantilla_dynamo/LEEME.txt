ADLB · Automatiza tus familias de Revit · Plantilla base de Dynamo
====================================================================

Archivos
  ADLB_Parametros_desde_CSV.dyn   grafico de Dynamo listo para abrir
  ADLB_Parametros_desde_CSV.py    codigo del nodo Python (el mismo que trae el .dyn)
  ADLB_Parametros_ejemplo.csv     tabla de ejemplo para copiar y editar

Uso rapido
  1. Abre la familia (.rfa) en el Editor de familias de Revit.
  2. Gestionar > Dynamo (desde la familia) y abre ADLB_Parametros_desde_CSV.dyn.
  3. Elige el CSV (y el archivo de parametros compartidos si lo usas).
  4. Corre con SIMULAR = True y EJECUTAR = True. Lee el registro.
  5. Si todo esta bien, SIMULAR = False y vuelve a ejecutar. Ctrl+Z deshace todo.

Requisitos: Revit 2022+ y Dynamo 2.x con motor CPython3. Sin paquetes externos.
La guia completa y la checklist estan en el PDF del kit.
